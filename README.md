# 消防作战信息卡制作工具

标准化数字作战卡系统：三套实战模板（图1·2 小区 / 图3·4 企业 / 图5·6 村社），地图战术标绘、双页 A4 横版制式输出、多格式导出（PNG / PDF / Word / JSON）。纯静态前端，无需后端。

## 功能特性

- 第 1 页：基本信息/单位基本概况表单 + 方位图（水源图）地图快照
- 第 2 页：总平面图（高精矢量制式图纸，可一键切换为地图实景标绘）
- 地图战术标绘：车辆出入口、消火栓、天然水源、重点单位、干线路名、着火点、手绘涂鸦等
- 多底图：高德电子/卫星、Esri、Carto、灰度
- 导出：双页 PDF、与 PDF 版式一致的双页 Word、可编辑表格版 Word、高清 PNG、工程 JSON 备份
- 工程数据保存于浏览器 localStorage

纯前端 CDN + 本地 vendor 双通道加载。
